## AI 算力与硬件

| 术语 | 我的一句话理解 | 补日期 |
| --- | --- | --- |
| HBM | 把 DRAM 垂直堆起来贴着算放，拿带宽换面积的产物；代价是抢走常规 DRAM 的晶圆产能 | 2026-10-30 |
| Chiplet | 把大芯片拆成小 die 再封装互连，绕开单芯片面积上限和良率诅咒；代价是封装复杂度与互连功耗 | 2026-10-30 |
| NPU / DSA | 用固定数据流换掉通用控制开销，所以同工艺下同功耗性能远超 CPU/GPU |  |
| 推理成本 | 训练一次的钱是资本开支，每一次调用消耗的那点算力才是长期账单 |  |
| Token 工厂 | 把「卖算力」变成「卖词元」：客户不买卡、按调用量付费，考验的是调度与推理栈，不是单卡跑分 | 2026-10-31 |
| 资本开支（CapEx） | 建机房、买设备的一次性大钱；和按调用量付的运营支出是两本账，听 AI 故事先分清在花哪本 | 2026-10-31 |

## EDA 与设计

| 术语 | 我的一句话理解 | 补日期 |
| --- | --- | --- |
| DTCO | 设计与工艺协同优化。概伦的说法贴切：是国产 EDA 的根技术，不是 STCO 的替代品，而是不同发展阶段的工程方法学 | 2026-10-30 |
| Signoff（签核） | 流片前最后一道权威验证。EDA Agent 能生成方案，但「验证靠签核」这条底线没变 | 2026-10-30 |
| PPA | Power / Performance / Area，芯片设计永恒的三角约束，改一头就得付另外两头的代价 |  |
| PDK | 工艺厂给设计方的一整套「规则 + 模型 + 库」。国产先进工艺覆盖率超 80% 才算能用 | 2026-10-30 |
| CDM 模型 | 充电器件模型，ESD 仿真的痛点，此前长期缺国产工具 | 2026-10-30 |
| 工具覆盖度 | 一家 EDA 能覆盖流程里多少环节；覆盖度不够客户就得混用多家工具链，切换成本反而成了替代门槛 | 2026-10-31 |

## 产业链七层（看到新闻先归层，再决定要不要读）

| 层次 | 关注要点 | 要积累的东西 |
| --- | --- | --- |
| 设备 | 光刻 EUV/High-NA、刻蚀、薄膜、量测，国产化进展 | 「某工艺节点用什么设备」的直觉 |
| 材料 | 光刻胶、大硅片、电子特气、化合物半导体 | 哪些环节被卡脖子、卡到什么程度 |
| 制造/工艺 | 先进制程节点、良率、Fab 扩产节奏 | 能看懂一条产线新闻的实际含义 |
| 设计与 EDA/IP | 数字前后端、模拟 IC、射频、验证方法学 | 与「模电/数电/半导体物理」直接呼应 |
| 封装测试 | Chiplet、2.5D/3D、TSV、先进封装产能 | 近三年最热、人才缺口最大 |
| 存储 | DRAM/NAND/新型存储、HBM | 价格波动最大，练周期感 |
| 政策与资本 | 出口管制、产业政策、并购、IPO | 理解行业为什么在这儿拐弯 |

## 金融与认知

| 术语 | 我的一句话理解 | 补日期 |
| --- | --- | --- |
| MLF 缩量续作 | 投放量小于到期量。若同期买断式逆回购加量，多半是期限结构置换而非收紧 | 2026-10-30 |
| DR001 | 隔夜质押式回购利率，央行已把它当作实际调控目标利率 | 2026-10-30 |
| 基金份额 vs 规模 | 判断「钱在不在跑」看份额，判断「赚没赚到」看净值，这两个数常讲相反的故事 | 2026-10-30 |
| 杠铃策略 | 一端红利防御、一端科技成长，中间地带不碰 | 2026-10-30 |
| 扣非净利 | 扣掉卖资产、政府补贴这类一次性收益后的利润；和归母净利的差额能看出主营到底赚不赚钱 | 2026-10-31 |
| LTA（长期供货协议） | 大客户与厂方提前锁量、锁价的多年期合同；把暴涨暴跌的现货价换成慢慢涨的长约，厂方让出涨价弹性换产能利用率，客户让出降价空间换拿得到货 | 2026-11-03 |
| 二阶导（derivative of growth） | 增速本身的变化率。看存储这类周期行业，涨价还在但涨得慢了，股价就会先跌——市场给的是二阶导的价 | 2026-11-03 |
| BOM 成本 | 整机的物料清单成本。存储器涨价最先打到 BOM，再传导到终端售价与出货结构 | 2026-11-03 |
| 合约价（Contract Price） | 原厂与大客户按季度或年度谈定的价格，和每天波动的现货价分开；这一轮 DRAM/NAND 的利润主要靠合约价一步步抬 | 2026-11-04 |
| 在手订单（Backlog） | 已经签下、还没交付的订单金额。判断「需求是真的吗」，它比营收更快、比发布会更实 | 2026-11-04 |
| 法说会 | 上市公司面向投资人开的业绩说明会。最有价值的不是结论，是它给的时间刻度（哪个季度最紧） | 2026-11-04 |
| 估值修复 | 跌多了以后向合理估值回摆，不等于趋势反转；区别在于盈利预测有没有跟着上修 | 2026-11-05 |
| CoWoS | 台积电的 2.5D 先进封装，把 GPU 和 HBM 装在同一块中介层上；它决定 AI 芯片能出货多少 | 2026-11-05 |
| 息税前利润率（EBIT margin） | 不算利息和税之前的利润率。跨公司比「谁更赚钱」时用它，比净利润干净 | 2026-11-05 |
| 回撤（Drawdown） | 从高点往下掉的那一段，是已经发生的事实。和波动不同：波动会回来，回撤之后要先问原来的理由还在不在 | 2026-11-06 |
| 拥挤交易（Crowded Trade） | 太多人押同一个假设、同一条逻辑。它的问题不在估值，在于一条反向消息会同时打中所有持仓 | 2026-11-06 |
